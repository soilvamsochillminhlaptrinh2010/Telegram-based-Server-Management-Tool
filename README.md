# README

This project was created by a Computer Science specialized high school student from the 2025–2028 cohort at **Le Quy Don High School for the Gifted – Nam Nha Trang**, Khanh Hoa Province, Vietnam. During the summer break, I decided to spend some free time finishing this side project.

## Overview

This is a server management system designed to monitor electricity costs and automatically update electricity pricing based on different countries.

The system includes:

- Server management utilities
- Electricity usage and cost monitoring
- Country-based electricity price updates
- A built-in help command listing all available commands
- Tools for installing **HopToDesk** and configuring its password directly through commands
- SSH setup instructions
- Integrated **ZeroTier** installation tools for secure remote access outside your local network

If you're away from home and need to access your server remotely without being on the same network, simply use **ZeroTier**. The required tools are already included, and you only need to follow the provided instructions. If anything is unclear, there are plenty of tutorials available on YouTube.

> **Important:** Every command in this system is executed through **Telegram**.

## Configuration

Before running the project, edit both `manager.py` and `check.py`.

Locate the following variables:

```python
TOKEN = ""
CHAT_ID = ""
```

- `TOKEN` should be your Telegram Bot Token.
- `CHAT_ID` should be your personal Telegram Chat ID. You can obtain it using any Telegram User Info bot.

Then configure your Gemini API key:

```python
GEMINI_API_KEY = ""
```

Replace it with your own Google Gemini API Key.

## Running the Project

### Linux

Open a terminal in the project directory and run:

```bash
./start_linux.sh
```

### Windows

Simply run:

```text
start_windows.bat
```

## Notes

- Linux is the recommended platform and has the best compatibility.
- Windows support is available, but the SSH feature may still have some known issues.
- On Windows, the system works best when your account:
  - is **not** signed in with a Microsoft account;
  - uses a traditional **password** instead of a PIN or other authentication methods.
- Windows 10 is recommended for the best stability.

## Compatibility
